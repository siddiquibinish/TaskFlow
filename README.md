# TaskFlow ✅

## Project Description
TaskFlow is a modern, responsive, and highly interactive To-Do list web application designed to help users manage their daily tasks efficiently. Built with a state-driven architecture, it ensures a seamless user experience with a clean UI, robust accessibility features, and professional development best practices.

## Features
- **Task Management:** Easily add, delete, and mark tasks as completed.
- **Dynamic Dashboard:** Real-time statistics showing Total, Active, Completed tasks, and a progress percentage.
- **Advanced Filtering & Search:** Filter tasks by 'All', 'Active', or 'Completed' status, and search through tasks in real-time.
- **Local Storage Persistence:** Your tasks are saved directly in your browser's local storage, meaning you won't lose your data even if you refresh or close the tab.
- **Smart Empty States:** Professional empty state illustrations and messages when no tasks exist or when search/filters return no results.
- **Keyboard Navigation & Accessibility:** Fully accessible for screen readers and keyboard users (e.g., using `Enter` or `Space` to manage tasks).
- **Security:** Built-in XSS protection by rendering user inputs safely as text content.

## Technologies Used
- **HTML5:** Semantic structure and accessibility attributes (ARIA).
- **CSS3:** Custom styling, Flexbox layout, responsive design, and CSS variables.
- **Vanilla JavaScript (ES6+):** State-driven data management, event delegation, DOM manipulation, and Local Storage integration.
- **FontAwesome:** For clean and modern UI icons.
